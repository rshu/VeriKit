## 功能说明

Agent Framework Kit（智能体框架服务）提供了拉起指定智能体的能力。应用在小艺开放平台上线智能体后，可以通过Agent Framework Kit的Function组件向用户提供应用+智能体组合的服务，让用户在适当的场景下主动拉起智能体。该Kit通过标准化组件满足应用在不同场景、不同界面下的智能体入口诉求。

Agent Framework Kit的核心组件是Function组件，它提供了一种标准化的UI控件能力，允许开发者将智能体入口集成到应用的各个界面中。用户通过点击Function组件即可直接拉起对应的智能体，与智能体进行自然语言交互。这种应用与智能体的组合模式，使应用能够借助AI能力为用户提供更智能、更便捷的服务体验。

开发者需要先在小艺开放平台上创建并上线智能体，配置智能体的能力和意图，然后在应用中集成Agent Framework Kit的Function组件，绑定对应的智能体即可实现拉起功能。该Kit支持多种场景下的智能体拉起，适用于客服咨询、智能推荐、内容生成、任务执行等AI增强场景。

## 使用场景

当开发者需要将AI智能体能力集成到应用中时，应使用Agent Framework Kit。如果你已经在小艺开放平台上线了智能体，并希望用户能够在应用内直接与智能体交互，Agent Framework Kit提供了Function组件作为标准化的智能体入口。

适用于需要为应用添加AI对话、智能客服、智能助手、内容生成等AI增强功能的场景。如果你的应用需要根据用户当前的操作上下文，在合适的时机引导用户使用智能体服务，Agent Framework Kit提供了灵活的组件集成方案。
