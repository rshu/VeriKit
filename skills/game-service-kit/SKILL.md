## 功能说明

Game Service Kit（游戏服务）主要提供快速、低成本构建游戏基本能力与游戏场景优化服务，有效提升游戏开发效率，帮助游戏运营。该 Kit 包含三大功能模块。

基础游戏服务（必选）为游戏快速构建基础功能，包括联合登录（支持华为账号登录、游戏官方账号登录、单机游戏登录）、华为账号实名认证、未成年人防沉迷等能力，让开发者聚焦游戏本身的业务能力。同时提供小游戏相关能力，支持小游戏的登录和支付功能。游戏场景感知（可选）通过游戏为系统提供精细化场景信息、配置信息、网络信息等数据，系统向游戏反馈系统状态等信息，使得双方能够利用这些信息进行更紧密和深入的协作，在系统资源有限的情况下优化玩家游戏体验。游戏近场快传（可选）支持设备在彼此靠近的情况下进行游戏数据交换，包括传输安装包和资源包。

基础游戏服务支持 Phone、Tablet、PC/2in1、TV 设备，游戏场景感知和近场快传支持 Phone、Tablet、PC/2in1 设备。该 Kit 同时提供 ArkTS 和 C/C++ 两种语言的开发指导。当前仅支持华为账号的服务地和注册地均为中国境内（香港特别行政区、澳门特别行政区、中国台湾除外）的用户，暂不支持模拟器。

## 使用场景

当您正在开发 HarmonyOS 平台上的游戏应用，需要接入华为账号登录、实名认证和未成年人防沉迷等基础能力时，应使用 Game Service Kit 的基础游戏服务。这是游戏上架华为应用市场的必选接入模块。

当您的游戏需要与系统进行深度协作以优化性能表现（如动态调整系统资源分配）时，应使用游戏场景感知功能。当您需要实现设备间的游戏安装包或资源包近场快速传输时，应使用游戏近场快传功能。当您正在开发小游戏并需要登录和支付能力时，也应使用该 Kit 提供的小游戏服务。
