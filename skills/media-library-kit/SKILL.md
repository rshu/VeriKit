## 功能说明

Media Library Kit（媒体文件管理服务）提供了管理相册和媒体文件的能力，包括图片和视频，帮助应用快速构建图片和视频的展示与播放功能。该Kit采用对象化API设计，支持端云一体化访问管理，提供安全精准的权限管控。

面向所有应用，Media Library Kit开放了Picker选择（系统图库选择器让用户选择媒体资源）、安全控件保存（通过SaveButton安全控件保存图片视频到图库）、动态照片管理（保存、获取、读取动态照片）、PhotoPicker/AlbumPicker/RecentPhoto组件（在应用中嵌入相册选择UI组件）、PhotoPicker推荐图片、PickerController编辑替换原图等能力。面向受限应用，还开放了媒体资源查询（获取指定媒体资源、缩略图、重命名）、用户相册管理（查询、重命名、添加/删除媒体资源）、系统相册访问（收藏夹、视频相册）、变更通知监听、MediaAssetManager C/C++接口等高级能力。框架层提供智能格式转化，统一完成不同格式之间的转换。

在开发范式上，Media Library Kit提供ArkTS和C/C++两种接口。C/C++接口通过MediaAssetManager请求媒体资源到目标沙箱路径。所有媒体资源操作需遵循标准路径表示方式和操作流程，确保数据安全和一致性。

## 使用场景

当您的应用需要访问、管理或展示用户设备上的图片、视频、动态照片等媒体资源时，应使用Media Library Kit。典型场景包括：通过系统图库Picker让用户选择图片或视频、在应用中嵌入相册浏览组件、将图片或视频保存到系统图库、播放动态照片、管理用户相册等。

当您需要开发相册应用、图片编辑器、短视频应用、文件管理器等需要操作媒体文件的场景，或者需要使用MovingPhotoView组件播放动态照片、使用RecentPhoto组件获取最近一张图片时，也应使用Media Library Kit。
