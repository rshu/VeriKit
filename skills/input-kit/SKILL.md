## 功能说明

Input Kit（多模输入 Kit）为 HarmonyOS 应用提供多种输入设备（触控板、触摸屏、鼠标、键盘等）的事件服务。通过对输入设备驱动事件的归一化处理，确保不同输入设备与用户的交互体验统一和流畅。Input Kit 除了提供基础的输入事件服务外，还提供了获取输入设备列表、改变鼠标光标样式、事件监听与事件拦截等能力。

Input Kit 支持 C/C++ 接口，开发者可以使用事件监听能力在录屏类应用中监听按键、鼠标、触摸和轴事件，也可以使用事件拦截能力在云桌面等应用中拦截特定输入事件，实现更灵活的输入控制。同时还支持优先响应系统功能键的定制，以及输入设备热插拔监听和键盘类型查询等设备管理能力。

## 使用场景

当您的应用需要自定义鼠标光标样式、监听输入设备的热插拔事件时，可使用 Input Kit 的鼠标光标和输入设备管理能力。

当您需要在录屏类应用中监听全局输入事件（按键、鼠标、触摸、轴事件），或在云桌面等应用中拦截特定输入事件进行自定义处理时，可使用 C/C++ 的事件监听和事件拦截能力。
