## 功能说明

Neural Network Runtime Kit（NNRt，神经网络运行时）是HarmonyOS面向AI领域的跨芯片推理计算运行时，作为中间桥梁连通上层AI推理框架和底层AI加速芯片，实现AI模型的跨芯片推理计算。NNRt通过Native接口对外提供服务，主要面向AI推理框架开发者和希望直接使用AI加速硬件实现模型推理加速的应用开发者。

NNRt提供在线构图、模型编译、模型推理、内存管理、设备管理、模型缓存和离线模型推理等核心功能模块。AI推理框架可调用NNRt的构图接口将模型图转换为NNRt内部模型图，实现无感知的跨AI硬件推理；也可直接使用硬件相关的离线模型文件进行推理，以更快的加载速度在特定AI硬件上执行推理。NNRt通过AI硬件驱动上的共享内存实现数据"零拷贝"，显著提升推理性能。

NNRt支持配置推理优先级、性能模式、FP16模式等常见硬件属性，也支持特定硬件的自定义扩展属性。模型缓存功能可将编译结果保存为缓存文件，大幅加快模型加载速度。NNRt与MindSpore Lite Kit紧密配合，两者共享MindIR模型图格式，使用MindSpore Lite在NNRt上加载模型比其他推理框架更高效。NNRt强依赖硬件，只适用于支持NPU的设备，目前支持56个常用算子，仅支持同步推理。

## 使用场景

当需要将AI推理框架对接到HarmonyOS的AI加速硬件（NPU）上执行模型推理时使用本Kit。NNRt提供统一的Native接口，让AI推理框架无需关心底层硬件差异，实现跨芯片推理计算。开发者可以按照模型构造、模型编译、推理执行三个阶段完成开发流程。

当需要直接使用离线模型在特定AI硬件上执行推理时也可使用本Kit。通过离线模型编译接口传入硬件厂商提供的离线模型文件，可以在特定AI硬件上快速加载和执行推理，适合对模型加载速度要求较高的场景。
