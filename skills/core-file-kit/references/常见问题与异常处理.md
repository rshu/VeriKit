# 常见问题与异常处理
#### 应用数据迁移暂停
**问题现象1**
在数据加载界面，应用数据迁移暂停。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/72/v3/0PM0teXDR6KGMk0nKsGD0A/zh-cn_image_0000002573974199.png?HW-CC-KV=V1&HW-CC-Date=20260421T110958Z&HW-CC-Expire=86400&HW-CC-Sign=6FF10402D80215E62FF025ECAEE4C22571BE47791E6EF804192532958FDDE0A7)
**可能原因**
应用数据迁移的过程中需要使用到网络，当前终端设备网络不可用，导致数据迁移暂停。
**解决方法**
单击“稍后连接WLAN加载”按钮，进入桌面后连接网络，终端设备网络可用后，恢复应用数据迁移。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/84/v3/15_UIDZ8QlWPZ7kkDkBioA/zh-cn_image_0000002543373972.png?HW-CC-KV=V1&HW-CC-Date=20260421T110958Z&HW-CC-Expire=86400&HW-CC-Sign=1EE4AD2F052891AF08076DB99CC292E6ECA0C2FEFAC039B0D1BD6ABFD170A2D3)
**问题现象2**
进入桌面之后，若应用数据迁移还未结束，可通过通知栏进入应用加载界面查看加载进度
在应用加载界面，应用数据迁移暂停。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/61/v3/AuHaOGplReKJTcAy9YspwA/zh-cn_image_0000002543214310.png?HW-CC-KV=V1&HW-CC-Date=20260421T110958Z&HW-CC-Expire=86400&HW-CC-Sign=615F2244E9A6E6475C98668E9815DA7A0648CD80C1D2DF393B52728254F70FED)
**可能原因**
应用数据迁移的过程中需要使用到网络，当前终端设备网络不可用，导致数据迁移暂停。
**解决方法**
单击“稍后连接WLAN加载”按钮，进入桌面后连接网络，终端设备网络可用后，恢复应用数据迁移。

#### 应用数据迁移执行十五分钟后失败
**问题现象**
应用数据迁移执行十五分钟后显示失败。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a4/v3/nUY7l4foQZCbQGhyGRSxRA/zh-cn_image_0000002543214308.png?HW-CC-KV=V1&HW-CC-Date=20260421T110958Z&HW-CC-Expire=86400&HW-CC-Sign=7DFE3D6293281F8F07E41B390294C4D2C7FDB312F6D5C70F857BBB35B571F06D)
**可能原因**
单个应用数据迁移执行超过十五分钟，超过设定的单个应用最长数据迁移时间，任务执行失败。
**解决方法**
请优化应用BackupExtensionAbility的代码实现，在十五分钟内完成应用数据迁移。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/be/v3/HiR-PDlYQ66oPMTy4xSpaA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T110958Z&HW-CC-Expire=86400&HW-CC-Sign=46C5282EBCA5034C10FA36AD2C31526AB41F73F26E3E90F9C5FC4A3FCEB74565)
已接入“数据迁移框架”的应用完成数据迁移后，才可以被消费者使用。尽可能快的完成应用数据迁移，可以带给消费者更好的体验。
