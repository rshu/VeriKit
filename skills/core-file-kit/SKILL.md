## 功能说明

Core File Kit（文件基础服务）为开发者提供应用文件和用户文件的访问与管理能力。按文件所有者不同，文件分为应用文件（应用安装文件、资源文件、缓存文件等）和用户文件（用户私有的图片、视频、音频、文档等）。应用文件支持查看、创建、读写、删除、移动、复制等操作，并提供应用沙箱隔离机制。用户文件通过FilePicker提供文件选择与保存能力，支持文档、图片、视频、音频等多种类型。

Core File Kit还提供应用数据备份恢复能力（基于BackupExtensionAbility框架）、应用数据迁移（HarmonyOS升级到HarmonyOS NEXT的数据迁移）、应用克隆适配等高级功能。分布式文件系统通过hmdfs实现跨设备文件访问，支持跨设备文件拷贝、文件共享和访问。端云文件协同提供端云一体的统一文件系统能力，支持文件同步、缓存和版本管理。

文件系统按存储位置可分为本地文件系统、分布式文件系统（跨设备访问）和端云文件协同（端云一体）。开发者可以使用ArkTS和C/C++两种语言进行文件操作。用户文件支持授权持久化，允许应用在用户授权后持续访问特定文件或目录。

## 使用场景

当你的应用需要读写自身沙箱内的应用文件（如配置文件、缓存数据、日志等），或需要通过FilePicker让用户选择、保存文件到用户目录时，可以使用Core File Kit提供的应用文件访问和FilePicker接口。

当你的应用需要实现数据备份恢复、需要适配HarmonyOS到HarmonyOS NEXT的数据迁移、或需要实现跨设备文件访问和端云文件同步等高级功能时，可以使用Core File Kit提供的相应能力。
