# 开发准备
请先参考 [应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview) 完成基本准备工作，再继续以下开发准备项。
#### 申请秒级启动开放能力
基于安全考虑，系统侧对秒级启动功能做了权限保护处理，使用相关接口开发者需先提交“秒级启动”能力开关的申请，在申请通过后，再使用该能力开关。
1.
登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“开发与服务”。
2.
在项目列表选择项目，并在应用列表下选择需要申请秒级启动功能的应用。
3.
进入“项目设置 > 开放能力管理”页面，点击“秒级启动”对应的“申请”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/ba/v3/vMp1GD45R3Wgch_1xNL4yw/zh-cn_image_0000002573974649.png?HW-CC-KV=V1&HW-CC-Date=20260421T111420Z&HW-CC-Expire=86400&HW-CC-Sign=A43C2ACE3E1C830BC5E7D4FA07B5706BD4000B0A03DDD1D735BDDA35D02B9047)
4.
参考“申请原因”中的模板，提供申请必需的相关信息，包括应用介绍、使用场景、申请用途，然后点击“提交”按钮。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/pSMssBMYR6yo-4lwIFh37A/zh-cn_image_0000002543374422.png?HW-CC-KV=V1&HW-CC-Date=20260421T111420Z&HW-CC-Expire=86400&HW-CC-Sign=9C319C0B4D1E23EDBFDF2FE1C35A03F056356A6BB43D674D5AA58C8B4BE1C2C5)
返回“开放能力管理”页面，原“申请”变为“申请中”，1~3个工作日内反馈申请结果，请留意互动中心的“服务开通申请”信息。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/WH7o1OPjQG6m_kpXyDNhfg/zh-cn_image_0000002543214760.png?HW-CC-KV=V1&HW-CC-Date=20260421T111420Z&HW-CC-Expire=86400&HW-CC-Sign=BA2E707F44CA88E0B46B494ABA705CC2A607FE05E90FFEFF100B2C4FA7297CCA)
申请通过后，互动中心会发送通知给您，同时“申请中”会变为置灰显示的“申请”，至此，应用已成功开启秒级启动开放能力。
