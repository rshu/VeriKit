# 测试函数
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/85/v3/WoQggSvyQs6dJ6Af1fLuhQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=0E384115A078D15644B8B8B02EC1E5E61FD3ED38F219D84C7DDF9D3D935FBE97)
下文以函数latest版本为例介绍测试方法。如果需要测试函数的已发布版本，可在已发布版本详情页面选择“函数代码”页签，参考方式二进行测试。
函数创建后可以在AGC控制台测试函数的代码运行是否正常。进入测试界面有两种方式：
-
方式一：函数列表中点击函数名称右侧“操作”列的“测试”，在右侧弹出的“测试函数”界面进行测试。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0a/v3/G-s538EdQYKO8y2-9KYHLA/zh-cn_image_0000002573854799.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=8C9F81AED763D59DB52F0B3B1DE89DB833CC36C3679A5864E8C0CBE2B0CFE2DC)
-
方式二：
1.
在函数列表中点击已创建的函数名称，进入函数详情页面。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/G3cUAFCqTGa9hRsR9ybZFw/zh-cn_image_0000002573974777.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=292203C13DF264145FCC93B91426051216C7D945481D9C327FABFB944ACC6A61)
2.
选择“函数代码”页签，点击“测试函数”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/dc/v3/sQWfPHYnQNydcw6TUz-HOw/zh-cn_image_0000002543374548.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=D51CF40AD1CAFC9D3E1E0F1F07AA44DC0F478AC4DC622386E925316A28694C6D)
3.
在右侧弹出的“测试函数”界面，使用默认测试事件、创建新测试事件或者使用已保存测试事件进行测试。
-
使用默认测试事件：直接点击“测试”对函数进行测试。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0b/v3/dEVHLo4SRI-7q9yldkM4Kw/zh-cn_image_0000002543214886.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=E6C08F7E483D63929088865F32EF49C8978A832DDCC73A5D886452DA2592BBD8)
-
创建新测试事件：如果需要设置调用函数的请求消息体，可按照如下步骤配置测试参数，并可保存为测试事件方便后续继续使用。
1.
在“事件”文本框中输入JSON格式的事件参数，点击“保存”。然后在“提示”弹出框中输入事件名称，配置完成后点击弹出框右下角的“确认”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/df/v3/xfH58bMnSF2YdzCKM4ekcw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=B9CCED3E5CEFA6264DA23916C00EB5BD22C17680BC70FDB5014CD9D494EC8926)
“事件”文本框内输入的JSON对象，对应的是触发器的event事件格式，会透传给函数。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/12/v3/b-9GbdYFQPyFYyE3oZkvMg/zh-cn_image_0000002573854801.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=EA8CD81FE86C9C384AE506B849E654EB48C4DA2B86EBE2885A01BC7481AB0FF1)
2.
点击“测试”，函数处理事件并返回测试结果。
-
使用已保存测试事件
1.
在“测试函数”界面，点击 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/73/v3/eG7szcIqRbWebtT0a0Wqhw/zh-cn_image_0000002573974779.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=85BEEDD52F159FF861E5554F9C01FC6AD88271D180817972C279FCD8C6748846) 展开已保存的测试事件列表，选择已配置的事件名称右侧的“加载”，然后点击“测试”，函数处理事件并返回测试结果。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/tj1QagqpTES5ko60aMsVAw/zh-cn_image_0000002543374550.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=2719BB8B0217337C65E7648609E665109895C0858798819516F0431DC8CEB689)
2.
（可选）如果需要删除已添加的测试事件，可在测试事件列表中点击事件名称右侧的“删除”即可删除测试事件。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/64/v3/vmDENoc-RA2PXP3qqY69NA/zh-cn_image_0000002543214888.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=33D784B84856374F9C31D5C62F5DF253A75350B5930B1095904F1610A274CCAD)
4.
查看测试结果。
-
执行结果：展示测试后获得的响应结果。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/3a/v3/T-lc9mM8TUCVksHJyLNBAg/zh-cn_image_0000002573854803.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=0FFE0EC5418FE61CEA65FE168D6ED32C85FFB350AB74A3B7584766323A8BF20C)
-
运行日志：展示函数运行过程中，通过logger API打印的日志，支持输出debug级别及以上日志（以下仅为日志输出示例）。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/d5/v3/ocMoOaPUQL6_rkBBzNdKGw/zh-cn_image_0000002573974781.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=DA76B1E3E6C21E8633827D62FD5B570F214F8C4187C814E04CD758548354B4B1)
-
执行摘要：展示该次测试请求相关信息。
- 请求ID：该条测试请求的RequestID，在后台日志中体现为X-Trace-ID。
- 持续时间：函数执行的端到端时间。
- 执行版本：该次调用测试的具体函数版本。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/1c/v3/DZKFCXJlT7S4KIybwRz-vQ/zh-cn_image_0000002543374552.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=A58DBA0DCE480C3809471709F2394472D33AC87A4CB5B9FEAFF90E131F468730)
5.
“代码输入类型”为“在线编辑”的函数，测试过程中，如果需要修改函数入口文件代码，可直接在“函数代码”页签的代码编辑器中修改，然后点击页面底部的“提交”。当界面提示更新函数成功时，则可以点击“测试函数”对更改后的代码进行测试。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/26/v3/kz5zdvIxRm63B0jR0O2Klw/zh-cn_image_0000002543214890.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=8484CC632A72E4E222D9E063CD0063D73DA211E1ACF331223C4617178C657242)
“代码输入类型”为“.zip文件”的函数，测试过程中，如果需要修改函数代码文件，可在本地修改且打包完成后，点击 ![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/36/v3/zzD-6z3aTEuwEB4AqBaNaA/zh-cn_image_0000002573854805.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=D9CFF133ECD4A2EAA66DA563D93CE825ED59F9834C897017F723EA6DDC5FD006) 重新上传函数部署包，然后点击页面底部的“提交”。当界面提示更新函数成功时，则可以点击“测试函数”对更改后的代码进行测试。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/db/v3/9YC46k2tQEiD3fh4BF-F9A/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=96A77BFA44C1803FFE38BC08A5E02795F75B74D46131D887F11F671480EE516B)
如果代码更新量比较大，需要调整函数内存配置，可点击“内存配置”下拉框进行调整，然后再上传函数部署包。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/08/v3/f7OxKOQSQAin6Ncteed4wQ/zh-cn_image_0000002573974783.png?HW-CC-KV=V1&HW-CC-Date=20260421T111504Z&HW-CC-Expire=86400&HW-CC-Sign=4CD75D144EC2B09046B6A6233F181FCBED30E7E8A4298330532394B7FD76D346)
6.
函数测试无误后，可在“函数代码”页签点击“导出函数”导出函数部署包。导出包以“函数名称+函数版本.zip”格式命名，可查看函数结构和文件内容。
