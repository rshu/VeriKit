## 功能说明

IME Kit（输入法框架服务）负责建立编辑框所在应用与输入法应用之间的通信通道，确保两者协作提供文本输入功能。IME Kit 提供输入法框架和输入法服务两类 API，支持开发输入法应用、自绘编辑框绑定输入法以及系统应用管理输入法的能力。

IME Kit 支持创建固定态、悬浮态、状态栏三种类型的输入法 Panel，开发者可以开发一个输入法应用同时部署在手机、平板等多设备中。同时还支持开发者自定义编辑框，实现绑定输入法应用并完成文字输入、删除、选中、光标移动等操作。

此外，IME Kit 还提供输入法子类型配置（支持多语言和多模式切换）、输入法应用沉浸模式、输入法安全模式（基础模式和完整体验模式）等高级能力，以及不可获焦窗口中输入框与输入法交互的处理方法。

## 使用场景

当您需要开发一款输入法应用时，可使用 IME Kit 的输入法服务 API 来创建软键盘窗口、插入删除字符、选中文本、监听物理键盘按键事件等。

当您的应用使用自绘编辑框（如游戏内的聊天输入框、富文本编辑器等）需要绑定输入法进行文字输入时，可使用 IME Kit 的输入法框架 API，支持 ArkTS 和 C/C++ 两种开发方式。
