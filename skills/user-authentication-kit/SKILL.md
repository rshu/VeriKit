## 功能说明

User Authentication Kit（用户认证服务）提供了基于设备本地注册的锁屏口令、人脸和指纹来认证用户身份的能力。该服务提供归一化认证接口，屏蔽不同认证因子差异，支持人脸、指纹、口令的组合认证。用户身份认证框架主要包括统一用户认证API、统一用户认证框架、统一用户认证控件和各种认证能力四个部分。

该Kit的亮点特征包括：归一化认证接口（同一套接口支持多种认证方式组合）、支持感知认证可信等级差异（ATL1-ATL4四个等级）、支持业务自定义认证方式、支持短时间内复用任意应用的认证结果（最长5分钟）、提供系统级用户身份认证控件、支持感知注册凭据的变化。

用户认证通过后，统一用户认证框架会在设备可信执行环境中签发AuthToken，该Token可用于与通用密钥库服务（HUKS）联动，作为密钥二次访问控制的用户鉴权证明。

## 使用场景

当你的应用需要验证用户身份才能执行敏感操作时使用本Kit，例如应用内账号登录、支付认证、敏感数据访问等场景。三方应用调用系统本地身份认证能力时，必须使用系统自带的身份认证控件。

当你的应用需要根据不同安全等级要求选择合适的认证方式时，可以通过指定认证可信等级（ATL）来确保安全性与便捷性的平衡。当需要避免用户频繁重复认证时，可以使用认证结果复用功能。
