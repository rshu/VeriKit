## 功能说明

Game Controller Kit（游戏控制器服务）支持游戏适配控制器外设（当前仅支持手柄），解决玩家操控性问题，保障用户体验。游戏开发者可通过接入该服务轻松实现游戏外设的上下线监听和按键及轴事件监听等功能。

该 Kit 通过 C/C++ 接口提供两大核心能力。设备上下线监听与查询能力支持注册设备状态变化事件监听，当手柄设备连接或断开时可收到通知，并可查询当前所有在线设备的详细信息（如设备类型、厂商信息等）。游戏手柄事件监听能力支持注册按键事件和轴事件的监听回调，按键事件覆盖手柄所有主要键位（A/B/X/Y、肩键、扳机键、方向键、摇杆按下等），轴事件支持左右摇杆的 X/Y 轴位移监听，帮助游戏实现精细化的手柄操控。

开发者需先完成设备上下线监听的开发后，才能进行按键和轴事件的监听注册。该 Kit 以 C/C++ 原生接口形式提供，适合与游戏引擎深度集成。

## 使用场景

当您正在开发需要支持手柄操控的游戏应用，需要监听手柄设备的连接和断开事件、查询在线手柄设备信息、以及捕获手柄的按键输入和摇杆轴位移输入时，应使用 Game Controller Kit。

该 Kit 适用于所有需要将手柄作为输入设备的游戏场景，包括动作游戏、赛车游戏、射击游戏、格斗游戏等各类游戏类型，帮助游戏实现完整的手柄操控支持。
