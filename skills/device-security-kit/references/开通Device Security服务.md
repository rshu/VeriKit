# 开通Device Security服务
在开通Device Security服务前，请先参考“ [应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview) ”完成基本准备工作，再继续进行以下开发活动。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/RgV1wxLnQo-QrUKD_WXE4w/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=59663ADFBE97528406D941913F250DEEC9B0C7D01DEB5A57C3681AB76DA84DDC)
Device Security包括应用设备状态检测、安全检测、可信应用服务、业务风险检测能力、数字盾服务，开发者请根据实际使用场景，选择开启某个或者多个能力开关。
1.
登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) 网站，选择开发与服务。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7/v3/T_4_USzxTYeYCr4gfNIvBg/zh-cn_image_0000002543214412.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=626D3D6E8469CA1AB072C1BE28D09F2BC84259267C237415A1B09D0D96D2693E)
2.
在项目列表中找到需要开通Device Security服务的项目。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/18/v3/VQeZV-H2RU2mI8bcZp6Xfg/zh-cn_image_0000002573854327.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=6ABE57AC86E621FF20FB8E2C26FB2997FB7DE9C030DDEF207C63391360C71B17)
3.
选择“开放能力管理”Tab页，找到需要使用的功能，点击左侧的按钮，开通相应的功能。
-
**应用设备状态检测** ：勾选“应用设备状态检测”并点击“保存”，接入“应用设备状态检测”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/2e/v3/og4lQi4tRIaNHPFIADe_WQ/zh-cn_image_0000002573974303.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=0096A26FA7A1BAD1D3818E205F5B2C3E32EF7A5B336BA719EA886755DA1208A2)
-
**安全检测** ：勾选“安全检测服务”并点击“保存”，接入“安全检测服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6/v3/t3NwyM-BSy-hkKH93M9b7w/zh-cn_image_0000002543374076.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=BA1A51EC2A8D215FD4EC06A36FF646BE7C7936DF71528D35BD6D47A2810C6E79)
-
**可信应用服务** ：勾选“可信应用服务”并点击“保存”，接入“可信应用服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/06/v3/9uPbntJZQq6nk4w8JkGpqg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=A48272D4386F98C56B41766591A72AC3B3A2C0FC4934EDABB7E995EE457C7470)
开通“可信应用服务”需要先申请进入允许清单，请将Developer ID、公司名称、应用名称、申请使用的服务和使用该服务的场景，发送到agconnect@huawei.com。AGC运营将审核相关材料，通过后将为您配置受限开放服务使用的名单，审核周期为1-3个工作日，请耐心等待。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7c/v3/IQhK6ZKuRwawTmVSt9ASfA/zh-cn_image_0000002543214414.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=F4490BB84A8AF457ED1DF525CB2D4472E876AF7AF8310C10748CBB502162D2FB)
-
**业务风险检测-涉诈剧本检测** ：点击“涉诈剧本检测”右侧申请按钮，接入“涉诈剧本检测”，审核通过后勾选对应服务并点击“保存”该服务配置。
① 在申请“涉诈剧本检测”前，需要在 [华为开发者联盟](https://developer.huawei.com/consumer/cn/) 网站上注册成为开发者，并完成 [企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489) 。
② 点击“涉诈剧本检测”右侧申请按钮，接入“涉诈剧本检测”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/a3/v3/OsmB8uEGSiKe5Pf3_jveng/zh-cn_image_0000002573854329.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=EB145455C7337A9C033CF6E715099A333D9A9370A724B3879568A49EADA82BA1)
③ 参考“申请原因”中的模板，提供申请必需的相关信息，包含Developer ID、公司名称、应用名称、使用场景、使用该服务的合法基础（应用使用该服务时需在其隐私声明中进行个人数据声明及用途说明，详细参考 [个人数据处理说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/devicesecurity-personal-data) ，并将合法基础的相关证明上传至申请附件），然后点击“提交”按钮。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4b/v3/hfFwSG-qSqeeicc0lIhx5g/zh-cn_image_0000002573974305.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=5990A10A88E124E40F7F50A31377F28A841489AF4FE18AFA92F63A83828BBE0D)
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/20/v3/1cFx1WxWQ66ypBAoI18rZg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=849C2A07B5B0E47503AECA5D717D96ABE960BA1462C3A8DB9769D9B49928BA9E)
提交申请后，AGC运营将审核相关材料，通过后则可保存对应的服务配置，审核周期为1-3个工作日，请耐心等待。
-
**数字盾服务** ：点击“数字盾服务”右侧申请按钮，接入“数字盾服务”，审核通过后勾选对应服务并点击“保存”该服务配置。
① 在申请“数字盾服务”前，需要在 [华为开发者联盟](https://developer.huawei.com/consumer/cn/) 网站上注册成为开发者，并完成 [企业开发者实名认证](https://developer.huawei.com/consumer/cn/doc/start/edrna-0000001062678489) 。
② 点击“数字盾服务”右侧申请按钮，接入“数字盾服务”，审核通过后勾选对应服务并点击“保存”该服务配置。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c8/v3/09YnuiK8ToWaWqETSYK0wg/zh-cn_image_0000002543374078.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=E924A61386B044A66B1A3952A998ABDE0F2EAD50B6D895E7E63268DAD659E329)
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/80/v3/_sf9YZ5sR92CD2tB0lTExQ/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=7D8DAACBD1A61F79F7DD9EAD5D70264E8E67B592255669DDD7E21DA698163F4F)
请您在申请框填写“数字盾服务”申请原因和应用场景。AGC运营将审核相关材料，通过后则可保存对应的服务配置，审核周期为1-3个工作日，请耐心等待。
4.
申请Profile（.p7b）文件，具体操作请参见 [申请调试Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-profile-0000002248181278) 。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/7d/v3/oHQars-aTJ6HflXOQzSMPg/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111106Z&HW-CC-Expire=86400&HW-CC-Sign=EF4294B761D250702635E3ADD6F0153BC36A804E9169294D111A5657525A4776)
在开通服务后，需要重新申请Profile（.p7b）文件。
