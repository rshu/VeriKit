# 开发准备
请优先 [开通地图服务](#开通地图服务) 后，再参考“ [应用开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/application-dev-overview) ”完成基本准备工作，然后再继续进行以下开发活动。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/cb/v3/5BOmDku4R9mYIFHimUzjFw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=5D3E6F93ED2C6B3A993B67F2E3D1FD091199A0D3B51B3C5ECB72E3055ACC5009)
-
从HarmonyOS 5.0.2(14)版本开始，开发者无需配置公钥指纹和Client ID。
-
从DevEco Studio 6.0.0 Beta5版本开始，支持在DevEco Studio中开通地图服务。
#### 开通地图服务
Map Kit提供2种方式开通地图服务：
-
通过DevEco Studio开通地图服务。
-
通过AppGallery Connect网站开通地图服务。
方式一：通过DevEco Studio开通地图服务
1.
登录DevEco Studio应用。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/27/v3/wjAzZBbGSbaEzYSCKFQINg/zh-cn_image_0000002543374694.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=7821F28F6683A81E017410114C166F10C60F6C6657EEAC56CA2032E732AC057E)
2.
选择文件，点击项目结构。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f2/v3/z96YVblMSaSXGzmr3SfUXA/zh-cn_image_0000002543215032.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=F088E05236A363145AA44A0E4D1BDE6AD4EF840519F3FEB19A0E64E5FD7C6565)
3.
进入“Signing Configs”页面，点击“Enable open capabilities”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f3/v3/a5BC-h7xQj2vj8fhlIsCIQ/zh-cn_image_0000002573854947.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=0FD3A12DBF48DE1E131ECAF5B76C560B736D3B497A1B65AC89E408E6B73E6F6F)
4.
勾选“Map Kit”选项，点击“OK”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/12Duv3GXRvqF0BZqqEerVg/zh-cn_image_0000002573974927.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=8D9F4151004D49DBDEDB9845E63340562AE5FFF38E7B230436047A7BFE3A05E8)
5.
选择“Apply”应用地图服务配置，点击“OK”完成地图服务配置。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/0f/v3/Cx6QvbrAQ7eVCA6CnOdT0A/zh-cn_image_0000002543374696.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=C6C06400C0391E892992593A2BEFD3E09380A2BCF042D4DC8AEE8C816CA6F37E)
方式二：通过AppGallery Connect网站开通地图服务。
1.
登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) 网站，选择“开发与服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/e8/v3/h--xZbd0QDSPUGGjHyZeTw/zh-cn_image_0000002543215034.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=29B1CE3C66920A555BCF7EE1F8E7988DDCC859CF2C1D00E8F80F2CFFCEE68391)
2.
在项目列表中找到您的项目，在项目下的应用列表中选择需要打开“地图服务”的应用。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c6/v3/f9rDBCzGTxWSIWD5LxRpwA/zh-cn_image_0000002573854949.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=E7179985841F78748F1EA19DF2D70DF03FB2AF47D77377ABCDF976CAB7F9FAD4)
3.
选择开放能力管理，找到“地图服务”开关，打开开关。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/c2/v3/GI0wEUujSKWO9CNKe3jE-A/zh-cn_image_0000002573974929.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=6BBFBEFBAC88974B90A62A8916C46B3FDCBA782D775D5E38FA2BAD2FAB619166)
4.
确认已经开启“地图服务”开放能力，并完成签名。
- 调试阶段必须[申请调试证书](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-debugcert-0000001914263178)、[注册设备](https://developer.huawei.com/consumer/cn/doc/app/agc-help-add-device-0000002283189937)、开启"地图服务"后重新[申请调试Profile文件](https://developer.huawei.com/consumer/cn/doc/app/agc-help-debug-profile-0000002248181278)，并完成[手动签名](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-signing#section297715173233)。
-
[申请发布证书](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-cert-0000002283336729)
[申请发布Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-release-profile-0000002248341090)
[配置签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app#section280162182818)
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/96/v3/fifEkCiGTS-N7ON5bjwreA/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111554Z&HW-CC-Expire=86400&HW-CC-Sign=5CDA09814CED825F2241AF0698F20AC81B45783E2B210CEE0C27C551033C5B09)
