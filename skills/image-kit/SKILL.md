## 功能说明

Image Kit（图片处理服务）为 HarmonyOS 开发者提供全面的图片处理能力，涵盖图片解码、编码、编辑、元数据处理和图片接收等功能。开发者可以使用 Image Kit 对 HEIF、JPEG、PNG、WebP 等主流图片格式进行编解码操作，并支持 HDR 图片处理和 AI 超分辨率等高级功能。

Image Kit 提供了 ArkTS 和 C/C++ 两套 API 接口。ArkTS 接口通过 ImageSource、ImagePacker、PixelMap、ImageReceiver 等组件完成图片处理全流程；C/C++ 接口提供了不依赖 JS 对象的 Image_NativeModule，支持多图对象编解码等新特性，推荐开发者在 C/C++ 场景下使用。

Image Kit 还提供丰富的图片编辑和处理能力，包括图像变换（裁剪、缩放、旋转、翻转）、位图操作（像素读写和区域处理）、滤镜效果（通过 ImageEffect）、EXIF 元数据读写、色彩空间转换、HDR 单双层转换、以及通过 VideoProcessingEngine 实现的 AI 超分辨率等。图片接收能力可配合相机预览流二次处理使用。

## 使用场景

当您的应用需要对图片进行解码显示、编码保存、格式转换等基础操作时，可使用 Image Kit 的编解码能力。当需要对图片进行裁剪、缩放、旋转等变换操作，或需要读写像素数据进行自定义处理时，可使用 PixelMap 或 Image_NativeModule 的位图操作能力。

当您需要处理 HDR 图片（单双层转换）、添加滤镜效果、读写图片 EXIF 元数据，或需要使用 AI 超分辨率提升图片清晰度时，也可以使用本 Kit 提供的相关高级能力。
