## 功能说明

Remote Communication Kit（远程通信服务）为HarmonyOS应用提供了场景化的网络请求能力，包括HTTP请求和URPC（Unified Remote Procedure Call）高性能远程过程调用两大核心能力。与Network Kit提供的标准HTTP能力不同，Remote Communication Kit构建了场景化API，强调易用性，开发者可根据需要选择合适的Kit。

HTTP请求能力支持GET、POST、PUT、DELETE、PATCH、OPTIONS、HEAD等多种请求方法，并提供请求拦截、缓存、断点续传、流式传输等高级特性。URPC通信库具备抗弱网传输、多径传输（蜂窝网络和Wi-Fi）等特性，可实现高效的远程函数调用。

开发者可以通过Configuration机制灵活定制DNS解析、代理设置、安全传输、数据传输处理等行为，同时支持拦截器机制实现更丰富的请求/响应定制能力。该Kit同时提供ArkTS和C++两种开发语言的接口支持，满足不同开发场景的需求。

Remote Communication Kit支持Phone、2in1、Tablet、Wearable设备，从5.1.1(19)开始新增支持TV设备。支持模拟器开发，但模拟器不支持URPC能力。

## 使用场景

当你需要在HarmonyOS应用中发送HTTP网络请求（如获取REST API数据、上传下载文件）时，应使用Remote Communication Kit。它提供了比Network Kit更易用的场景化API，并内置缓存、拦截器、断点续传等高级特性，减少开发工作量。

当你需要实现高性能的远程过程调用，特别是在弱网环境下需要抗弱网传输或多径传输能力时，应使用URPC通信库。URPC可以实现简单方便的远程函数调用，适用于对网络质量要求较高的实时通信场景。
