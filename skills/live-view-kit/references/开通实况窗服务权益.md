# 开通实况窗服务权益
1.
登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“开发与服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6a/v3/sZmErDKMSH67D2zDurTMnA/zh-cn_image_0000002543215002.png?HW-CC-KV=V1&HW-CC-Date=20260421T111549Z&HW-CC-Expire=86400&HW-CC-Sign=30E863C613D6EFB33E498E6CA078206E88826C5E168D414BE93EC9F6A9FA6534)
2.
在项目列表中找到您的项目，在项目下的应用列表中选择需要申请实况窗服务的应用。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/P61DuiBlSgqi_N7sgE1_Pg/zh-cn_image_0000002573854917.png?HW-CC-KV=V1&HW-CC-Date=20260421T111549Z&HW-CC-Expire=86400&HW-CC-Sign=3197D339C52889A0B7E069E496FE3B84ABA3516A0962D270BE6910CE1CEF214B)
3.
进入“项目设置 > 开放能力管理”页面，点击“实况窗服务”的“申请”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5e/v3/MNV16jCRQeydDzqEvR6pGg/zh-cn_image_0000002573974897.png?HW-CC-KV=V1&HW-CC-Date=20260421T111549Z&HW-CC-Expire=86400&HW-CC-Sign=B0BD5A477C3A68142E5CCD0BF184EBECD27DE90F8A3C07AF4917AE5967549F3D)
4.
开发者可参考“申请原因”中的模板，提供申请必须的相关信息，包括场景类型、场景描述、附件，然后点击“提交”按钮。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/f1/v3/g0Jf5GVaR36z6vKqKdhY-g/zh-cn_image_0000002543374666.png?HW-CC-KV=V1&HW-CC-Date=20260421T111549Z&HW-CC-Expire=86400&HW-CC-Sign=091F224125355DACE29C0D9D0E63210B89A27B053D090898B0A071422375B6B6)
5.
开发者将在5个工作日内收到实况窗服务权益申请结果，请留意互动中心的“服务开通申请”信息。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/b9/v3/7tRsOi44SZqT9V4cFI9xxA/zh-cn_image_0000002543215004.png?HW-CC-KV=V1&HW-CC-Date=20260421T111549Z&HW-CC-Expire=86400&HW-CC-Sign=1D8E6FD71C310FF189F41D56EAC18F6F2A0F9EB74EC309D6D8AB936F5D23A9BB)
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/4f/v3/tKAQ8CyqQ6iM4RbBEg2qZw/zh-cn_image_0000002573854919.png?HW-CC-KV=V1&HW-CC-Date=20260421T111549Z&HW-CC-Expire=86400&HW-CC-Sign=E1A96656C4C32584206D668CE972A9D196338E71CB82E31DBD099E68FD74E85A)
6.
实况窗服务权限通过后，须在“证书、APP ID和Profile”页面下左侧树形菜单的“Profile”页签，点击“添加”重新生成Profile文件，并下载Profile文件到本地，然后在“ [发布应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app) ”时，须将该Profile打包到应用包中。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/5a/v3/4YxQn_xNSG2i_fHg0zxjOw/note_3.0-zh-cn.png?HW-CC-KV=V1&HW-CC-Date=20260421T111549Z&HW-CC-Expire=86400&HW-CC-Sign=29EBCE421F5B3BCB2D32ABFEB84AC1CF62733BC5D13581759879186E388F728C)
Profile文件生成请参考“ [管理Profile](https://developer.huawei.com/consumer/cn/doc/app/agc-help-profile-0000002270709473) ”章节，Profile文件打包到应用包中请参考“ [配置签名信息](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app#section280162182818) ”。
