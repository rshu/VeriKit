# 申请优先通知权益
当用户终端收到携带 [priorityNotificationType](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/js-apis-inner-notification-notificationrequest) 字段的通知消息时，系统会将其识别为优先通知并优先显示。
申请优先通知权益存在以下限制：
1）该优先通知消息仅对商务办公、社交类应用开放。
2）应用仅在重要联系人、@我、加急消息、重要日程类提醒等场景下使用该能力。
#### 申请步骤
1.
登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) ，选择“开发与服务”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8a/v3/6r8nO_6ZRwSQQBf4CLep9g/zh-cn_image_0000002573974993.png?HW-CC-KV=V1&HW-CC-Date=20260421T111608Z&HW-CC-Expire=86400&HW-CC-Sign=10B02995AAA94C57B4E82ED4669F208B3CCEAD40E5A54ECCF3D9C67E6A496AF5)
2.
在项目列表中找到您的项目，在项目下的应用列表中选择需要申请优先通知权益的应用。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/8d/v3/mPnlgZbWTJCKK-k_ritI-Q/zh-cn_image_0000002543374760.png?HW-CC-KV=V1&HW-CC-Date=20260421T111608Z&HW-CC-Expire=86400&HW-CC-Sign=D771BB9323FA364DC18491CE76735C5664FDCD7DC5030A073BF358CA7591B109)
3.
进入“项目设置 > 开放能力管理”页面，点击“优先通知”的“申请”。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/34/v3/FHgV0zixRrO39k8O5O9GBw/zh-cn_image_0000002543215098.png?HW-CC-KV=V1&HW-CC-Date=20260421T111608Z&HW-CC-Expire=86400&HW-CC-Sign=6A6FD0FD168B8C8F621C9768E9459EBA78CE777D90F8337357E4427E3CCF9A1E)
4.
开发者可参考“申请原因”中的模板，提供申请必须的相关信息，包括应用介绍、使用场景、申请用途、附件、承诺信息，然后点击“提交”按钮。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/aa/v3/x1y67k4FQc29XMU-v3WWfQ/zh-cn_image_0000002573855013.png?HW-CC-KV=V1&HW-CC-Date=20260421T111608Z&HW-CC-Expire=86400&HW-CC-Sign=5BD0F30D18A2E93C83B01BD5BEAC256CF27CCF860AD0C304DB9ABC75DE8D0F55)
5.
开发者可通过互动中心的“服务开通申请”消息获取优先通知权益申请结果。
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/6c/v3/-sspAypRSYCj5rNJGzHyRw/zh-cn_image_0000002573974995.png?HW-CC-KV=V1&HW-CC-Date=20260421T111608Z&HW-CC-Expire=86400&HW-CC-Sign=235F880CED4958C0A844185C67B32124FA4C8FCD53C30CDF641F6A93DEF1126F)

6.
优先通知权益申请通过后，须在“证书、APP ID和Profile”页面下左侧树形菜单的“Profile”页签，点击“添加”重新生成Profile文件，并下载Profile文件到本地，然后在“ [发布应用](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/ide-publish-app) ”时，须将该Profile打包到应用包中。
