## 功能说明

Function Flow Runtime Kit（函数流运行时服务，简称 FFRT）是一种并发编程框架，旨在简化并发编程和任务调度的复杂性。FFRT 采用基于任务的调度方式，开发者只需关注任务及其依赖关系而无需处理底层的线程和计算资源；同时采用基于协程的任务执行方式，可以提高任务并行度、提升线程利用率并充分利用多核平台的计算资源，保证系统对所有资源的集约化管理，最终解决系统线程资源滥用问题。

FFRT 编程模型具有三大核心特性。Task-Based（以任务方式组织应用）特性允许开发者以任务粒度组织应用程序，任务之间可直接指定依赖关系或通过数据对象表达依赖，支持任务嵌套形成父子任务关系，多任务支持同步操作（等待、锁、条件变量等）。Queue-Enabled（队列约束执行）特性提供串行队列（确保任务按提交顺序依次执行，适用于保持特定执行顺序的任务流）和并发队列（允许多个任务同时执行并支持约束整体并发度，适用于并行计算和高效利用多核处理器）。Graph-Driven（图驱动调度）特性支持通过任务依赖（Task Dependence）和数据依赖（Data Flow）两种方式构建任务依赖图，管理复杂任务关系实现高效调度。

此外，FFRT 还提供任务伙伴（Job Partner）功能，支持多线程协作和动态并发调度。FFRT 同时提供 C 和 C++ 两套 API，并内置超时监测和长耗时任务监测等维测机制，帮助开发者快速定位性能问题。该 Kit 支持模拟器运行调试。

## 使用场景

当您需要开发高性能并发应用，希望以任务为单位组织程序逻辑而避免直接管理线程的复杂性时，应使用 Function Flow Runtime Kit。相比传统线程编程模型，FFRT 在用户态以协程方式调度执行，调度开销更小，且由运行时负责工作线程池的创建和管理，可有效避免线程资源滥用和负载不均问题。

当您的应用包含复杂任务依赖关系、需要精细控制任务执行顺序和并发度、或需要通过任务依赖图管理多任务协作时，应使用该 Kit 提供的串行队列、并发队列和图依赖并发能力。此外，当您需要对多线程任务进行协作调度时，可使用任务伙伴功能。
