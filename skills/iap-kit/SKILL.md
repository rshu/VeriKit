## 功能说明

IAP Kit（应用内支付服务）为 HarmonyOS 开发者提供便捷的应用内支付体验，帮助开发者快速实现应用内商品购买和商业变现。开发者可以通过 IAP Kit 提供的系统级支付 API 启动 IAP 收银台，支持消耗型商品、非消耗型商品、自动续期订阅商品和非续期订阅商品四种商品类型的购买。

IAP Kit 涵盖了从服务开通、商品配置、购买接入、权益发放、沙盒测试到收益分析的完整支付流程，同时提供退款、开票等售后服务能力。开发者可以在 AppGallery Connect 中管理商品信息，配置签名和应用身份信息，并通过沙盒环境完成测试验证后正式上线。

IAP Kit 还支持嵌入式收银台组件（适用于 TV 设备），提供 developerPayload 参数处理机制，以及完整的签名校验和 JWT 验签安全保障。本 Kit 适用于 Phone、PC/2in1、Tablet、Wearable、TV 设备。

## 使用场景

当您的应用需要实现虚拟商品购买功能（如游戏货币、道具、会员订阅等）时，可使用 IAP Kit 的购买接入能力。当您需要管理自动续期订阅商品的切换、续费逻辑时，可使用订阅相关能力。

当您需要处理购买后的权益发放、退款处理、发票开具等售后流程，或需要查看收益分析报告时，也可以使用本 Kit 提供的完整支付生命周期管理能力。
