## 功能说明

Form Kit（卡片开发服务）提供了一种在桌面、锁屏等系统应用上嵌入显示应用信息的开发框架和 API，可以将应用内用户关注的重要信息或常用操作抽取到服务卡片（简称"卡片"）上，通过将卡片添加到桌面、锁屏等系统应用上，达到信息展示和服务直达的便捷体验效果。卡片架构中涉及三个核心角色：卡片使用方（如桌面应用，负责展示和交互）、卡片提供方（提供卡片的应用或元服务，负责 UI 和数据更新）、卡片管理服务（操作系统内管理整机卡片信息的系统服务，作为桥梁连接使用方和提供方）。

Form Kit 支持两种卡片开发范式。ArkTS 卡片基于声明式开发范式，支持动效、自定义绘制（Canvas 组件）、逻辑代码运行、自定义字体等增强能力，分为动态卡片和静态卡片两种类型，拥有独立的进程模型。JS 卡片基于类 Web 范式（HML+CSS+JSON），支持 Stage 模型和 FA 模型。此外还提供互动卡片能力，包含趣味交互类型（支持卡片小游戏）和场景动效类型（支持动态效果展示），以及锁屏卡片（在设备锁屏界面显示重要信息或快捷操作）和背板透明卡片等特殊卡片类型。

卡片提供丰富的交互能力，包括 message 事件（卡片传递消息给应用）、router 事件（从卡片跳转到应用页面）、call 事件（拉起应用 UIAbility 到后台）等。在数据刷新方面支持主动刷新和被动刷新（定时刷新），可根据卡片状态刷新不同内容，支持刷新本地图片和网络图片。卡片还支持应用内直接拉起卡片管理页面并添加到桌面。支持手机、平板、PC/2in1、智慧屏、智能手表、车机等设备，轻量级智能穿戴设备不支持使用本 Kit。

## 使用场景

当您希望将应用的关键信息或常用操作以卡片形式展示在用户桌面或锁屏上，实现信息一目了然、服务一步直达的用户体验时，应使用 Form Kit。典型场景包括：天气应用在桌面展示实时天气卡片、待办应用在桌面展示任务列表卡片、音乐应用在锁屏展示播放控制卡片、运动应用在桌面展示今日运动数据卡片等。

当您需要开发带有交互动效的趣味卡片（如卡片小游戏、动态场景展示），或需要卡片支持自定义绘制、自定义字体、动效等高级 UI 能力时，应选择 ArkTS 卡片开发方式。当您的卡片需求较为简单且团队熟悉 Web 开发范式时，可选择 JS 卡片开发方式。
