## 功能说明

File Manager Service Kit（文件管理服务）为开发者提供文件管理相关能力，开发者通过该 Kit 可完成文件删除到回收站、获取文件图标、解析文件快捷方式等功能，满足用户对文件管理的多样性诉求。

该 Kit 提供三个核心功能。删除文件到回收站功能支持将公共目录的文件删除并移至回收站，使误删除的文件可以通过回收站恢复，避免数据永久丢失。获取文件图标功能支持根据文件类型（如文档、图片、视频等）获取对应的文件图标，帮助文件管理类应用快速展示美观统一的文件类型图标。解析文件快捷方式功能支持根据快捷方式文件解析出对应原文件的 URI，方便应用追踪和访问快捷方式指向的实际文件资源。

该 Kit 适用于手机、平板和 PC/2in1 设备，从 5.1.0(18) 版本开始支持模拟器运行调试。仅支持在中国境内（香港特别行政区、澳门特别行政区、中国台湾除外）提供服务。

## 使用场景

当您正在开发文件管理类应用，需要提供将文件移入回收站而非永久删除的安全删除功能时，应使用 File Manager Service Kit 的删除文件到回收站能力。这适用于文件浏览器、文件清理工具等需要管理公共目录文件的应用场景。

当您的应用需要根据文件扩展名或 MIME 类型展示对应的文件图标，或需要解析快捷方式文件以获取其指向的原文件 URI 时，也应使用该 Kit 提供的相应功能。这常见于文件管理器、桌面启动器、文档查看器等应用。

## 典型场景

- 如何将公共目录文件删除到回收站而非永久删除以支持恢复
- 如何根据文件类型（文档、图片、视频等）获取对应的文件图标
- 如何解析文件快捷方式获取其指向原文件的URI
