## 功能说明

Core Vision Kit（基础视觉服务）为HarmonyOS应用提供了一系列开箱即用的机器视觉AI能力，涵盖通用文字识别（OCR）、人脸检测、人脸比对、主体分割、多目标识别和骨骼点检测六大核心功能。开发者无需深入了解AI模型细节，通过简单的API调用即可在应用中集成智能视觉能力，大幅降低AI应用开发门槛。

该服务支持多种具体的视觉识别场景：通用文字识别支持简体中文、英文、日文、韩文、繁体中文等多种语言的印刷体文字识别，适用于文档扫描、票据识别、名片录入等场景；人脸检测可定位图片中的人脸矩形框、五官关键点和人脸朝向信息；人脸比对支持1v1人脸相似度比较，可用于身份认证和考勤打卡；主体分割能检测并分离图片中区别于背景的前景主体；多目标识别可同时检测图片中的动物、植物、建筑、人、文本等多种目标并给出位置信息；骨骼点检测可识别人体17个关键骨骼点，支持智能监控、人机交互和运动员辅助训练。

Core Vision Kit支持Phone、Tablet、PC/2in1设备类型，仅适用于中国境内（不含港澳台地区），当前不支持模拟器。各AI能力对输入图像的质量和尺寸有明确约束，建议输入720p以上质量的图像以获得最佳识别效果。该服务支持多用户同时接入，但不支持同一用户并发调用同一特性，同一进程多次并发调用会返回系统繁忙错误，不同进程调用同一特性时会排队处理。

## 使用场景

当你的应用需要处理图像中的文字信息时，例如实现文档扫描、票据识别、名片管理、表单自动录入等功能，可以使用通用文字识别能力。当需要构建基于人脸的身份验证系统，如门禁管理、考勤打卡、实名认证等场景时，可以组合使用人脸检测和人脸比对能力。

当你的应用涉及智能相册管理、照片美化、前景提取、图片编辑等功能时，可以使用主体分割能力来实现背景替换或前景提取。多目标识别适用于端到端业务场景的前置检测，根据检测结果完成后续功能入口提示，例如视觉搜索和文本检测。骨骼点检测则适用于智能视频监控、病人监护、虚拟现实、人体动画、智能家居、运动员辅助训练等需要人体姿态分析的场景。
