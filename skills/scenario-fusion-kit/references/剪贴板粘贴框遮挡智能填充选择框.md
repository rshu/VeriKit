# 剪贴板粘贴框遮挡智能填充选择框
**现象描述**
![](https://contentcenter-vali-drcn.dbankcdn.cn/pvt_2/DeveloperAlliance_scene_100_1/82/v3/Hvf3P_bjQ-moN56Xp4LMCg/zh-cn_image_0000002573855109.jpg?HW-CC-KV=V1&HW-CC-Date=20260421T111643Z&HW-CC-Expire=86400&HW-CC-Sign=AEBC678CEA39FCCE22817C538FCEF3E812B2A6EC4BD370BF27CB139047CD0CD8)
**解决措施**
在代码文件中设置.selectionMenuHidden(true)，使剪贴板粘贴框隐藏。
```typescript
Row() {
        Text('收货人：').textAlign(TextAlign.End).width('25%')
        TextInput().width('75%').contentType(ContentType.PERSON_FULL_NAME).selectionMenuHidden(true)
      }
```
